# Python Port Scanner

A simple TCP port scanner written in Python that scans a user-specified range of ports on a target host, identifies open, closed, and filtered ports, and optionally generates a scan report.

## Features

* Scan a custom range of TCP ports
* Detect open, closed, and filtered ports
* Display standard service names for well-known ports
* Input validation for port ranges
* Connection timeout handling
* Progress indicator during scanning
* Measure total scan duration
* Save scan results to a text report

## Concepts Implemented

* Socket Programming
* Exception Handling
* File I/O
* User Input Validation
* Python Standard Library
* Performance Timing
* Network Service Identification

## Files

* **scanner.py** – Main port scanner application.
* **server.py** – Simple local TCP server for testing the scanner.
* **report.txt** – Example scan report generated by the application.

## Requirements

* Python 3.x
* Uses only Python's standard library (`socket`, `time`, and `datetime`)

## How to Run

1. Run `scanner.py`.
2. Enter the target IP address.
3. Enter the starting and ending port numbers.
4. Wait for the scan to complete.
5. Choose whether to save the results to `report.txt`.

To test locally, start `server.py` in one terminal and scan `127.0.0.1` using the server's listening port.
